One word from your ex: **Avoidant**. Therapy-speak turned self-own — the ex who says you never let them in. It stings because it is a diagnosis, not an insult, and the entrant plainly knows it. The program scores a shortlist of ex-words against the judge's five criteria (a single word an ex would actually use, funny on its own, painfully true, lands instantly, relatable) and writes the winner to `/output/entry.txt`. Avoidant ties Clingy at 49 points and wins the tie-break: the most obvious word is the likeliest to match a house anchor text, and an entry byte-identical to an anchor never enters the playoff — so on a tie, the less obvious word wins.

## Run it

```sh
node main.ts
```

It writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
